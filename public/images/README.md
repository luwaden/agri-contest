# Site photography (dummy images)

Every file here is a **labelled placeholder**. To use a real photo, save it over the file with the **same name** (keep `.jpg`). No code change needed.

| File | Where it appears | Ideal size | Notes |
|---|---|---|---|
| `story.jpg` | "A contest and a classroom" section | 1200×900 (4:3) | People at work |
| `kaduna.jpg`, `niger.jpg`, `nasarawa.jpg` | Focal-state tiles | 900×700 | Bottom is darkened for the state name |
| `gallery-1.jpg` … `gallery-3.jpg` | "Life in the field" strip | 1200×800 (3:2) | Farm to market · Processing hubs · Training |
| `hero.jpg` | Hero background (**off by default**) | 1920×1080 | Enable in `config/media.ts` |
| `cta.jpg` | Closing banner (**off by default**) | 1920×800 | Enable in `config/media.ts` |

Tips: keep each file under ~400 KB (compress at squoosh.app), use real, rights-cleared photos only, and update the `alt` text in `config/media.ts` to describe the real image.
The hero and closing banner keep the animated wind-blown field scene until you enable their photos.
